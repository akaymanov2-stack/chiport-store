# Handoff: Inspector AT850 — лендинг в одну прокрутку

## Overview
Продающий одностраничный лендинг (single-scroll) для бытового алкотестера **Inspector AT850**.
Задача страницы — за одну прокрутку провести посетителя от «что это» до кнопки покупки:
первый экран с оффером → доказательство цифрами → бытовые сценарии боли → сравнение технологий
сенсора → инструкция в 3 шага → комплектация и характеристики → FAQ → финальный CTA.

Язык интерфейса — русский. Тон копирайта — продающий, с акцентом на выгоду покупателя,
без канцелярита, без восклицательных знаков, без эмодзи.

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные на HTML**. Это прототипы, показывающие
задуманный внешний вид и поведение, а не продакшн-код для копирования как есть.

Задача — **воссоздать эти макеты в существующей среде целевого проекта** (React, Vue, Next.js,
Svelte, SwiftUI, нативный код и т. д.), используя принятые в нём паттерны, библиотеки компонентов
и систему стилей. Если среды ещё нет — выбрать подходящий фреймворк и реализовать дизайн в нём.

`docs/reference/at850-landing.dc.html` открывается в браузере напрямую (рядом лежит `support.js`)
и работает как эталон: сверяйтесь с ним по отступам, размерам и состояниям, но переносите
разметку на свой стек.

## Fidelity
**High-fidelity (hi-fi).** Все цвета, типографика, отступы, скругления и радиусы — финальные,
указаны точными значениями ниже. Копирайт — финальный, кроме цен (заглушки, см. «Content»).
Воссоздавать следует пиксель-в-пиксель, подставив компоненты своей кодовой базы.

## Interactions & Behavior
- **Навигация:** якорные ссылки `#buy` (шапка, hero, финальный блок) и `#how` (hero → секция шагов). При переносе в SPA — плавный скролл к секции; достаточно нативного `href="#id"` либо `window.scrollTo({ top, behavior: 'smooth' })`.
- **Ховеры:**
  - основная кнопка: фон `#1447E6` → `#0B31A8`;
  - вторичная кнопка: `border-color: #D8DFE9` → `#0B1220`;
  - белая кнопка на синем CTA: фон `#FFFFFF` / текст accent → фон `#0B1220` / текст белый.
  - Переход по умолчанию мгновенный; при желании добавить `transition: background-color .18s ease, border-color .18s ease`.
- **Шапка** прилипает к верху, полупрозрачная с блюром — фон под ней должен просвечивать.
- **Адаптив:** только через `auto-fit` в грид-контейнерах и `clamp()` в типографике.
  Медиазапросов в макете нет; на узких экранах колонки складываются в одну автоматически.
  Проверить: hero-панель с фото сохраняет `min-height: 600px` — на мобильном допустимо снизить.
- Анимаций, модалок, загрузочных и ошибочных состояний в макете нет.

## State Management
Собственного состояния у страницы нет — это статический маркетинговый лендинг.
Параметризованы только следующие значения (в прототипе — props компонента, в проде разумно
вынести в CMS / конфиг):

| Параметр | Тип | Дефолт | Назначение |
|---|---|---|---|
| `price` | string | `2 490 ₽` | Актуальная цена; выводится в шапке, hero и CTA |
| `oldPrice` | string | `3 290 ₽` | Зачёркнутая старая цена; hero и CTA |
| `ctaText` | string | `Купить сейчас` | Текст всех основных кнопок |
| `showComparison` | boolean | `true` | Показ секции сравнения сенсоров |
| `showFaq` | boolean | `true` | Показ секции FAQ |

Кнопки покупки в прототипе ведут на якорь. В продакшне их следует подключить к корзине /
форме заказа / внешней витрине.

## Статус переноса
Лендинг **ещё не свёрстан** в проекте: `docs/reference/at850-landing.dc.html` — это макет
в формате Design Composer, а не продакшн-код. Порядок работы:

1. Верстать лендинг на `css/design-system.css` — токены и компоненты уже реализованы там
   (кнопки, чипы, карточка, панель, метки, полоса цифр, шаги, FAQ, таблица характеристик).
2. Специфику страницы класть в отдельный `css/at850.css` — по образцу `css/vitrina.css`.
3. Копирайт брать дословно из `docs/at850-copy.md`, раздел «Готовые тексты».
4. Технические утверждения о приборе — только из списка фактов в `CLAUDE.md`.
5. Эталон `.dc.html` не трогать: это точка сверки, как секции должны выглядеть.
