# chiport-store

Витрина товаров для Wildberries под трафик Яндекс.Директа и дизайн-система бренда,
общая с лендингом алкотестера Inspector AT850.

Статика без сборки: HTML + CSS, никаких зависимостей и шагов установки.

## Страницы

| Страница | Статус |
|---|---|
| `index.html` — витрина товаров | готова, нужны реальные данные вместо заглушек |
| Лендинг Inspector AT850 | не свёрстан; эталон макета — `docs/reference/at850-landing.dc.html` |

## Локально

Открыть `index.html` в браузере — этого достаточно, относительные пути к `css/`
и `assets/` работают через `file://`.

## Превью

**https://raw.githack.com/akaymanov2-stack/chiport-store/main/index.html**

Отдаёт файлы прямо из ветки `main`, обновляется сразу после пуша, отдельной сборки нет.
Ссылка для согласования, не для рекламы: сторонний прокси, без гарантий аптайма
и с ограничением по трафику.

### Почему не GitHub Pages

В аккаунте есть репозиторий `akaymanov2-stack.github.io` с доменом `kaymanov.ru`.
GitHub Pages подтягивает домен пользователя ко **всем** проектным сайтам аккаунта:
проект автоматически появляется на `kaymanov.ru/<repo>/`, а адрес на `github.io`
отдаёт 301 на этот же домен. Независимой ссылки на `github.io` при такой конфигурации
не существует, поэтому Pages для этого репозитория отключён — личный домен занимать
не надо.

Когда для проекта купят свой домен, схема меняется: в настройках Pages репозитория
указывается его собственный custom domain, он перебивает наследование от аккаунта,
и проект живёт на своём адресе, не задевая `kaymanov.ru`.

## Деплой

Залить на хостинг `index.html` и каталоги `css/` и `assets/`.
Каталоги `docs/` и файл `CLAUDE.md` на хостинге не нужны.

## Перед публикацией заменить заглушки

- реквизиты продавца и контакты в футере (сейчас нули);
- `data-ym-counter` у `<body>` — номер счётчика Яндекс.Метрики;
- `href` кнопок «Купить на Wildberries» и `data-nm` (артикул) на каждой карточке;
- `href` кнопки «Открыть магазин на Wildberries»;
- цены (для AT850 сейчас 2 490 / 3 290 ₽ — заглушки);
- цифры в тёмной полосе статистики — сверить со своими условиями;
- ссылки «Политика конфиденциальности» и «Публичная оферта».

Юр-блок в футере обязателен для модерации Яндекс.Директа: страница не должна выглядеть
пустым редиректом на Wildberries.

## Дизайн-система

Спецификация — `docs/DESIGN_SYSTEM.md`, реализация — `css/design-system.css`.
Правка на все страницы бренда идёт в `design-system.css`, правка одной страницы —
в её собственный файл.

Ключевые правила: без градиентов, без эмодзи и рисованных SVG, одна тень на страницу,
ховер меняет только цвет, адаптив на `auto-fit` и `clamp()` без медиазапросов.
Единственное согласованное исключение — фирменный градиент Wildberries на кнопках,
ведущих на площадку (`.btn--wb` в `css/vitrina.css`).

## Аналитика

Клик по кнопке с классом `.buy` шлёт цель Метрики `buy_wb` (тип «JavaScript-событие»).
По ней настраиваются автостратегии Директа — сам факт покупки Wildberries обратно
не передаёт. Класс `.buy` вешать только на ссылки, ведущие на карточку товара.
